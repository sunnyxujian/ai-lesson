让 Claude Code 通过代理访问模型

## Light-plus
让你的 AI 编程工具调用模型服务的时候，要去调用你这个代理服务器，不然的话，它会直接去走这个模型服务，那肯定不行。现在几乎所有的AI开发工具，它都支持配置，就是你要发到哪个地址，都可以配置的。目前我还没有见过哪个开发工具是不能配置的。那现在问题是，我也不知道你使用的是什么样的AI开发工具，你自己去搜一下吧，你的开发工具怎么去配置这个东西啊？我这里呢，开发工具倒是挺多的，关键是我就没必要一个个去讲了。反正开发工具呢，我后面会说。

那我这里就以这个 Claude Code 为例吧。我这里呢配置的方式呢是通过这个 CC Switch 。这个有些同学可能知道，有些同学可能不知道，呃不重要，后边我都会说的。总之呢，你们反正自行去配置。我这里呢是启用了一个 Kimi-Proxy ，就是希望这个 Claude Code 呢调用的是我这个代理服务。我这个代理呢，要转发到 Kimi 那边。因为我这里用的不是 Claude Code 官方的模型，我用的是 Kimi 的模型。用啥模型其实都无所谓了，这个我后边会说。

你经常的问哪个模型好，哎呀，我哇，这种事情我以后会说。好，这里就编辑一下就可以了。你看，我编辑的就是这个地址，请求的是什么？我们的代理服务器，看到没？放大一点。其他的呢配置呢都没有什么变化。然后呢，我就把这个东西启用。目前就启用的是个代理。那么后续的Claude Code呢，他就走这个代理服务了。那么其实在这里吧，也可以看到，它其实就是给你生成这么一个配置。我靠，我的 Key 都暴露了，暴露就暴露吧。
