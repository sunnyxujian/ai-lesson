# 认识模型服务接口 · Slidev 交互演示

25 页中文演示，面向熟悉 HTTP / JavaScript 的开发者。素材来自同级 `share/完整教程.html` 和 `share/重点演示稿.html`，原文件未修改。蓝色标记是教学模拟或本地计算，绿色标记是真实 API。

## 启动

需要 Node.js 22.12+ 和 pnpm。在本目录运行：

```sh
pnpm install
# 本机已预留空白 .env.local；复制项目到新电脑时执行：
cp .env.example .env.local
pnpm dev
```

打开 http://127.0.0.1:3030 。按方向键／空格推进页面及点击步骤，使用 Slidev 演讲者视图查看中文备注。交互组件提供自己的按钮，操作组件不会翻页。不要使用 `--remote` 对外开放带凭据的本地代理。

## 配置百炼

在 `.env.local` 填写：

```dotenv
MODEL_BASE_URL=https://llm-u0vlqrit84y13fo8.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
MODEL_API_KEY=
MODEL_NAME=
```

填写自己的 key 和该服务实际可用的模型名称，保存后重启 `pnpm dev`。地址是 API 基地址，不要重复添加 `/chat/completions`。不要把 key 发到聊天中或提交到 Git。已有 `.env.local` 时不要重复复制模板覆盖它。

密钥仅由 Vite 开发服务器的代理读取，不使用 `VITE_` 环境变量。浏览器调用同源 `/api/demo/chat`，由代理拼接百炼 `/chat/completions`。SDK 代码页用于教学，实际代理使用服务端 `fetch`。代理只允许本机同源请求，一次只执行一个请求，不自动重试，60 秒超时。取消本地等待不保证上游停止计算或不产生费用。

未配置凭据也能使用所有教学图。第 4、21 页只在手动点击发送时调用真实模型；不会将失败替换成模拟答案。temperature/top_p 默认省略，勾选后才发送。若服务不支持参数，显示接口错误而不静默删参。返回用量缺失时显示“未提供”。本项目不包含公开部署后端。

## 演示路线

- 1–8：服务层次、接口规格、HTTP／SDK、服务商配置。第 4 页可查看真实请求和回复，第 5 页点击变换代码，第 6 页切换配置示意。
- 9–14：费用、前处理、访问权限、消息角色、Tokenization。原课价格仅为历史算例，不是百炼报价。
- 15–19：概率分布、自回归、两次追加、输出轮次与采样位置。第 16、17 页支持单步、播放、暂停和重置。
- 20–23：温度数学实验、百炼 A/B、top_k、top_p。A/B 需相同消息；切换记录可核对发送时快照，修改当前表单不会改写历史记录。
- 24–25：后处理和全流程回顾。

原教程、原演示稿、原有参考 PDF 及关键帧复制到 `public/reference/`，页脚链接直接跳转相应章节。样式使用本机中文字体，不引用远程字体。首次安装依赖需要联网；真实模型调用需要联网；教学计算不访问模型。Slidev 源码项目需本地服务启动，不是双击 HTML 的交付形式。

## 教学边界

- Token 切分、角色标记和数字 ID 使用小型示意词表，不是百炼真实 tokenizer。
- 自回归固定生成“我是模型助手。”，候选分布也为教学定义，不展示真实模型内部概率。代码高亮表示**下一步将执行的行**。
- 采样实验使用原课 `[0.30, 0.25, 0.20, 0.15, 0.10]`，真实计算概率；T>0 用 `p^(1/T)` 后归一化，T=0 使用最大项。top_k/top_p 独立演示，不指定真实服务的组合顺序。
- 温度 2 仍非等概率；真实服务温度 0 不保证跨运行绝对一致。单次 A/B 不足以得出统计结论。
- 生成轮次只是逐 Token 教学循环，不能等同真实 GPU 调用次数。实际系统有 KV cache、批处理等优化。
- 后处理检查分支是示例，不代表百炼内部流程。历史价格、原课行业观点不作为当前平台事实。

## 静态检查

```sh
pnpm check:syntax
pnpm typecheck
# 或统一执行
pnpm check
```

`check:syntax` 解析 Slidev Markdown、检查 25 页及备注、Vue SFC、代码片段 TS 语法和本地引用。`typecheck` 检查组件、本地代理和配置的 TypeScript 类型。遵照任务要求，不运行 `slidev build`、导出或浏览器自动化。

## 人工验收清单（本次不自动执行）

1. 启动并逐页查看 25 页，确认 16:9 布局、正文与备注、点击动画、页脚章节链接；确认字体和图片无需 CDN。
2. 第 10、11、24 页分别执行正常和失败路径；切走页面停止播放，返回保留位置，重置回初始状态。
3. 第 12–14 页切换系统消息，推进到 ID，聚焦词块检查映射；确认角色标记没有消失。
4. 第 16 页单步：output 先追加、input 后追加；播放至 EOS，不把 EOS 收进正文；离开停止计时器。
5. 第 20 页验证 T=1 为原分布、T=0 只选第一项、T=2 仍不等概率；切换参数后统计归零。
6. 第 22 页 K=1 只保留首项，K=5 全保留；第 23 页 P=0.8 保留四项、0.75 保留三项、1 全保留；排除项抽样为零。
7. 环境变量为空时：真实请求按钮不可用，提示缺失字段，本地实验仍可操作。
8. 填好模型与 key 并重启：手动发一次请求，核对真实回复、耗时及返回用量。切换到 A/B，比较相同消息不同参数的快照。
9. 用本机自选的测试配置检查认证失败、无模型权限、参数不支持和网络超时；确认显示错误、不自动重试、不展示模拟结果。
10. 请求中不能并发再发一组；取消或离开页面中止本地请求；不要据此断言上游没有计费。

当前交付验证以实际静态检查结果为准。密钥和模型尚未填写，未进行真实百炼调用；浏览器布局和交互仍需以上人工验收。
