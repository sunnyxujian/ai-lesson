## 标题
打开交互网页并设定三个输入

## Light-plus
权重乘以每个输入，加起来，加上偏置，再经过激活函数，得到最终输出。这就是一个神经元的模型。

接下来看一个界面。我做了一个网页，把运行方式写到 Makefile 里了。先用 `make install` 安装依赖。我用前端实现这个演示；这里口述的框架名识别为 React，原计划使用的可视化库名识别为 Matplotlib，这两个名称需以配套源码为准。之前想用那个库做，后来发现做这个东西实在太难为它，就用前端做了。

不管你懂不懂前端都无所谓，直接运行出来看效果，只是为了学习方便。用 `make dev` 运行，打开看看单个神经元的工作原理。

你可以把中间这个东西理解为一个神经元。假设它接收三个输入 x₁、x₂、x₃。是什么意思？它不知道，对它来说什么都不知道，只知道收到三个数字。但我们人可以规定。

假设 x₁ 表示年收入，单位是万/年，比如 30 万一年；第二个数是信用分，比如 750 分；第三个是负债率。比如背了房贷、车贷等贷款，负债率怎么算先不用管，反正是一个数字。假设负债率是 30%。把这些作为 x₁、x₂、x₃ 输入进去。

## Visual explainer
操作过程先在终端运行 `make install` 安装依赖，画面可见它执行 `cd HTML && pnpm install`；Makefile 的 `dev` 目标执行 `cd HTML && pnpm install && pnpm dev`，因此用 `make dev` 启动演示。浏览器打开 `localhost:5173/#/neuron`，标题为“单个神经元—贷款审批决策”。三个输入控件依次是收入（万/年）、信用分与负债率；连线标注对应权重，圆形节点右侧显示 y。
