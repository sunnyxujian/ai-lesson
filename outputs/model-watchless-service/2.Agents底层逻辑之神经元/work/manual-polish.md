每个神经元都有一个特征：它有很多这样的分支，叫什么呢？叫树突，我给你写一下。多个树突用来接收信号，各种各样的信号可以通过树突传到神经元内部。然后它还有一个轴突。单个轴突是用来输出信号的。

你可能会说：不对啊，图里后面不也分叉了吗？不用管它，不用管它。这里实际上只有一个输出。分叉是为了把这一个、同样的输出传递给其他神经元，意思是把相同输出传给不同的神经元，而不是有不同的输出。

树突就不一样了：这里接收到的每一个信号可能都不一样，是有差异的。反正记住，神经元有多个树突和单个轴突。轴突的输出取决于接收到什么信号，中间经过一段运算，得到一个输出信号。这就是神经元的工作模式。

神经元的工作模式，如果用数学表达，应该是什么样的东西？输出信号 y 应该等于一个函数 f，把多个输入传进去。多个输入就是多个信号，信号一、信号二……是不是可以看作一个一维数组？在数学上，我们把这样的一组数叫作向量。

比方说 [x, y]，可以认为它是一个向量。在横纵坐标系里，[2, 1] 就是 x 为 2、y 为 1，对应这个点。三个信号呢，就是三维向量，放在空间中。比方说 [1, 2, 3]，就是 x 为 1、y 为 2、z 为 3，大概是空间中的这个点。

实际模拟神经元时，这个向量的维度可能非常多，几百、上千、上万维，那就是更高维的空间了。我无法想象，图也画不出来。但是你简单地把它认为是一个一维数组，也没有问题：各种各样的信号传进来，经过一个函数转换，得到一个输出信号。

输出信号是什么？输出信号是一个标量，也就是单个数字。生物学里，它是不是数字？肯定不是。我们是在模拟，也不可能完全建立一个碳基生物；我们要建立的是硅基生命，只能用数字模拟，它只会数字，其他不会。因此，基于现实世界中的神经元，就可以为它建立一个数学模型。这件事发生在 1943 年，已经很久远了。

这里的 y 是什么？就是轴突的输出结果。它怎么来的呢？经过很多个 x 的计算。这里是一个求和公式，展开后就是这个样子。输入是 x₁ 到 xₙ，多个数字、多个信号。每个信号分别乘上一个东西：w₁、w₂、w₃……这些也全都是数字。这里没有字符串、对象之类的东西，全是数字在运算，因为这是数学模型。

这里写错了，应该是 xₙ，要一直写到最后一个输入。每个 x 乘一个权重，wᵢ 就叫权重，b 叫偏置：一个叫权重，一个叫偏置。概念很抽象，对不对？然后外面这个是激活函数。这是什么东西？背后有数学道理，但现在不太好解释，你先感性地认识一下。总之，通过这套公式能算出一个 y。

把公式写完整，就是：y = σ(w₁x₁ + w₂x₂ + … + wₙxₙ + b)。

这些概念先理解，后面会用可视化交互图演示。输入是什么？是外界传进来的向量，一个多维向量 [x₁, x₂, …, xₙ]。这个向量是什么含义？含义是人来定的，你说它是什么含义，它就是什么含义。

输入的含义是人来定的。我举个例子，随便举个假设：输入一个三维向量。实际情况可能是很高很高的维度，这里只用三个数字举例。

输入 [25, 11, 33]，我告诉你：25 是 2025 年，11 表示程序员、前端开发，33 表示他在这一年年薪是 33 万。这是人赋予它的意思。神经元本身知道这些含义吗？知道这是年份、职业编号、年收入吗？知道单位是万吗？它什么都不知道，也不需要知道，就这么神奇。

它经过一串运算，算、算、算，算出来一个 y。假设 y 是 0.8，它自己都不知道 0.8 是什么意思。反正经过一串运算，它算出来了，得到 0.8。

那 0.8 到底是什么意思？由人规定。假设我现在研究的话题是：给一个年份、职业编号，以及这一年在这个职业中的薪资，希望它给我下一年薪资的涨幅预测。注意，这全是我的期望、我的美好想象、我的做梦、我的梦想。

我的梦想是什么？有一个特别厉害的神经元，我给它这些信息，它算一下就给我算出一个东西，而且这个东西恰好是正确的。我期望的就是这个。所以，这是人来规定的。在不同领域下，给它输入的东西，含义都完全不一样。

比方说，在图像识别领域，这个向量里可能是每个点的 RGB，还有 A：第一个点的 R、G、B、A，第二个点的 R、G、B、A……依次输入。这样就是一个很高维的向量。

计算机知道它是什么意思吗？计算机里建立的数学模型知道是什么意思吗？它完全不知道。你给我什么，我管你给的是什么，我就算。我希望的是，它算出来刚好正确。比方说，给它一张图像，它吐出来一个数字 2，这个数字恰好对应 ID 为 2 的动物——猫，而图片里刚好就是猫，它就对了。我期望的是这么一个神奇的效果。

但是整个过程中，计算机压根不知道你在干什么。即便到现在，你们平时用的模型也是一样。你给它聊对话、喂图片、说话，可以骂它，也可以夸它，它都不知道你在干什么。对它来讲，里面全是数字：给它一串数字，它又吐出一个数字，它不知道这些有什么含义，什么都不知道。

这个世界上就是有这么神奇的事情。所以说，你会觉得这节课大开眼界：它不知道这是什么意思，也不知道那个是什么意思，但吐出来的结果就恰好符合我们的预期。

总之，输入值就是人为规定的一串数字。我们知道是什么意思，它自己不知道。扔给它，经过一连串运算，得到一个输出值。输出值也叫激活值，是一个标量、单个数字。它也不知道是什么意思，反正就是这么算出来的。

现在要研究，什么东西在影响这个结果。我希望给你一串数字，你算出的东西一定有现实意义。虽然你不知道这个现实意义，我们人知道。在不同领域，现实意义不一样：图像识别和薪资预测，含义都不一样。我希望输出符合这个领域里的预期。不同领域的预期不同，所以各自有自己的模型。

如果不加控制，就完全乱来了，没有意义。接下来要研究什么东西导致输出结果变化；找到了，就可以调控它。首先，输入值能不能调控？输入是人给它传进去的，不同情况下输入不同：今天问的是 2025 年程序员收入 33 万，也可能有一天问 2024 年做前台的收入，请它预测下一年。每次输入不一样，这个你咋调控？这是外界输入，对这个神经元来说不可控。

能控制的是什么？是 w₁、w₂，一直到 wₙ。这些叫权重，每个都是数字。权重表示每个信息维度的重要程度。比如年份有多重要？我们来算：w₁×25 + w₂×11 + w₃×33 + b，b 等会儿再说。

假设 w₁ 是 0.3，说明不是很看重年份。w₂ 比方说是 1.2，比较看重你是什么行业。w₃ 假设是 0.8，比较看重你之前的薪资水平。假设这三个权重取这些值，通过三个值就可以调控输出。看到没？把一个值改小，它对输出的影响就小；把另一个调大，对输出的影响就大。

我这是瞎写的，全是瞎写的，用来说明权重的含义。权重到底应该取多少？不知道，不知道是多少，需要调控。一个神经元到底能不能输出正确结果，很大程度取决于权重。为什么结果对了？因为权重调对了。

权重调对了，给它任何数据，结果好像都是对的、都还比较接近现实情况。给它任何一张图片，把图片的数字给它，它都能预测出正确物体的 ID。我查一下 ID，确实，这张图片是狗，那张是猫。我希望的是这样。我希望调控这些东西，让神经元达到我们预期的输出结果。这就是权重。

那么 b 是什么意思？b 叫偏置。要理解偏置，先看最终的 y。y 是一个标量，像刚才说的 0.2。在这里的讲解中，我们要求这个标量不能小于零。为什么不能小于零？背后有数学原理，不过这里不打算讲，我讲一个比较直观、你们能理解的例子。

就像生物学：你给我输入没问题，我接收。但输入以后，我发现跟我没关系。大脑有很多神经元，你现在听课，跟逻辑、语言、计算机相关的神经元在疯狂工作，在激活、在做事情；但很多神经元处于休眠，不干事。比方说跟吃东西、饥饿相关的，现在工作吗？不工作。跟玩游戏相关的，现在工作吗？不工作。跟看小姐姐跳舞相关的，现在工作吗？不工作，沉睡着。

它有没有接收到信息？其实接收到了。我不停说话，声音传过去，它接收到了。但它不输出、不工作、沉默。我们把这种状态叫作未激活。你给我信息，但这个信息好像跟我没关系，我就沉默。神经元有这样的激活状态，所以输出值也叫激活值，就是这里输出的 y。

假设算出来是 0，就表示：你给我的信息跟我没关系，我不干活，未激活。注意，权重可以有负数。那如果算出来是 -10，跟 0 是不是一样？在这里都表示不激活。讲解中把负数理解为会干扰运算，所以往往要去掉，一会儿再说怎么去掉。

理解激活的含义了吗？有激活，也有不激活。激活还有程度：0.2，有点激活；0.5，比较激活；也可能是 100，就相当激活、非常活跃了。当然，一般也不太会取到 100 那么大的数字，通常就是几个数字。要么是 0，完全不激活、完全休眠；要么有一点点激活。这就是这里说的激活含义。理解它之后，再来理解 b。

b 叫偏置。有些神经元可能有一个特点：必须算出来大于 10，我才激活。它有一个阈值，就像一道阀门；没超过阈值，我就睡着。

在现实世界里怎么理解呢？比如饥饿。每个时候可能都有一点饿，刚吃完饭，你说能不能再吃下东西？还是能吃的。但饥饿要达到一个阈值，你才能感觉到，才激活，觉得“我要吃东西了”。它有这么一个阈值，可以这样理解偏置。

比方说，算出来的数字可能要达到某个值，神经元才激活。我再说一次：在不同领域，这个数字的含义不一样。假设需要大于 10，我就可以把偏置设为 -10。没有大于 10，比如前面算出 5，5 减 10，不行，激活不了。这样就能通过偏置调节。

反过来，有些神经元在前面结果是 -10 时，就希望到达激活门槛，那这里可以加 10。前面哪怕算出来 -10，加 10 也能到 0；再多一点点，马上就能激活。是这个意思，能理解吗？

偏置这个东西，你大概知道什么意思就行。这里不能求甚解，因为一求甚解，就得讲背后的数学原理，这就有点恼火，没必要，没必要。知道它大概什么意思就行。最后说激活函数。

激活函数就是对最终的计算结果作一个处理。处理方式有很多，激活函数也有非常多种。比方说这个以前很著名、长期使用的函数，虽然现在还有更复杂的函数，但它很有用。

它怎么做？把前面一串运算求得的值跟 0 求最大值。就像刚才说的，小于 0 在这个例子里没有意义；结果是 -10，就直接取 0。这个函数就是 ReLU：ReLU(z) = max(0, z)。

现在的一些激活函数加了更复杂的东西，但使用这个函数也没有什么问题，特别是训练一些小模型的时候。过去一直用它：跟 0 取最大值，负数不要，直接砍掉负数。这个激活函数简单吧？

再看公式，是不是没有那么复杂了？权重乘以每个输入，再加起来，然后加一个偏置，通过一个激活函数，就得到最终的输出结果。

我希望的不是只对这个输入有效，还要对其他输入也有效。比方说把收入换成 35 万，信用分变成 350 分。输出不能还是 1.26，可能得是别的值，那就要重新调。而且调的时候，还要尽量不要影响刚才那个结果。

这个过程不是靠人参与去调，人没法调这么多。你知道最终这个东西叫什么名字吗？权重和偏置加在一起，有一个共同的名字，叫作参数。参数是什么？就是权重和偏置，统称参数。

你们知道现在神经网络有多少参数吗？平时看新闻就知道，这里课程举的是几万亿参数的说法。人怎么调？人怎么调？没法调，调不了，得靠机器自己调。具体怎么调，是后面课程要说的。

现在要清楚：对于单个神经元，它能调的只有这些，统称参数。输入是外界传过来的，跟它没关系；在这里的模型设定下，能调整并影响输出结果的是这些参数。

关键问题就在于，怎样调整参数，让神经元带有智能，好像给它任何输入都能得到预期结果。训练模型、训练神经网络，本质上是在做这个事情：在这个行业、这个领域里，给它输入，它都能得到一个我们看上去正确的结果。就在做这个事，就在调这些东西。

现在讲的是单个神经元，后面会讲多个神经元。但前提是先把单个神经元理解清楚，知道什么叫参数。它能调的就是这些东西，没有别的东西可调，只能调这个。
@@15
没有别的东西可调，只能调这些。你可以把它看成仪表盘上的各种旋钮开关：怎么调它，让结果符合我们的预期？不但这个结果符合预期，其他结果也符合预期。问题就在这里。

最后总结这节课：单个神经元接收一个向量，多维数字传进来，输出一个标量，也就是一个数字。输入是向量，输出是标量。

然后，当前讲解里激活函数是固定的，一开始就选好了。具体是什么函数，这里先不用去考虑。原讲解把它说成“定死的，它不影响输出”，这里保留这个语境：本次调参过程中不改变激活函数，而不是说激活函数不参与输出计算。

能调的只有参数，就是权重和偏置。在当前模型设定下，它们决定这个神经元的输出是否正确。这个神经元的智能程度，就看权重和偏置到底取什么值。就是这个问题。
