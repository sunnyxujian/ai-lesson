## 标题
把损失看成参数的函数

## Light-plus
看着：在输入固定的情况下，标签是不是也固定？想一想。输入是“1”，标签就只能是那个样子，因为它是人类标注好的。所以输入固定，标签也固定。

要改变损失度，是不是只能动输出？但输出能直接动吗？不能直接动。什么影响输出？参数。所以现在什么影响损失度？我们可以认为是参数在影响损失度。这个逻辑要想清楚：输入和标签都固定，要改变损失，只能改变输出；要改变输出，只能改变参数。因此参数间接影响损失度。

参数和损失之间一定存在某种关系，只是关系太复杂。这个小网络有两万多个参数；讲到更大的模型时，我用一万多亿、约 1.5 万亿参数来举例，强调计算规模会大得多。到底每个参数怎样影响损失度，关系非常复杂。

数学里遇到这种情况，可以用函数来记：有一个 x，经过一段非常复杂的计算，得到 y，就说 y 与 x 有关系。具体关系是什么，即使暂时不展开，也可以写成 y = f(x)。在损失这里，我们用 cost 这个单词，用 C 表示这个函数。传入 C 的是参数；你心里要知道，这个“参数”实际是一整组数值，并不一定只有一个。

这一组参数经过复杂的运算，最后得到损失 y。把它写出来有什么意义？我们的目标就是考虑怎样改变参数，使 y 减少，也就是让损失减少。

现在先考虑最简单的情况：假设只有一个参数，而不是两万多个。一个 x 经过复杂函数得到一个 y，应该怎样改变 x 才能让 y 减少？接下来用一张示意图来看。
