# 神经网络 · 交互实验室

双击本目录的 `index.html` 即可打开。整个目录可以单独复制使用；不需要安装依赖、启动服务器或联网。右上角“课程资料”链接需要保留原课程目录才能访问。

## 四个入口

| 课程        | 地址                   | 主要操作                                                        |
| ----------- | ---------------------- | --------------------------------------------------------------- |
| 2. 神经元   | `index.html#/neuron`   | 输入数值、加减按钮、拖动/键盘旋钮、精确参数输入、两组课堂预设   |
| 3. 前向传播 | `index.html#/forward`  | 四步播放、暂停、回退、换样本、随机参数、节点明细、矩阵行列浏览  |
| 4. 梯度下降 | `index.html#/backward` | 八步反传、单轮/连续训练、更新快照、损失曲线、二维/三维下山      |

旋钮支持上下拖动、方向键（0.01）、Shift + 方向键（0.1）、Home/End，以及数值输入。网络节点支持鼠标点击和键盘 Enter/空格。

## 演示依据与计算口径

视觉依据来自上级目录中各课程 `share/keyframes/` 和 `share/*-visual-explainer.md`，对应的原视频位于工作区 `model/`：

- 神经元：第 11—14 场景，重点参考 `scene_013_00-20-29.jpg` 的布局、旋钮、输入值和计算链。
- 前向传播：第 2、5—8 场景，重点参考 `scene_008_00-11-55.jpg` 的四列网络与四步操作区。
- 反向传播：第 10、14、15 场景，参考输出期望箭头、隐藏层贡献汇总及三栏参数调整面板。
- 训练模式：第 1—8、11—12 场景。原课主要复用反传页面和讲解截图；批次、遗忘、张量、拟合等交互为本次补充实验。

单神经元使用收入 / 100、(信用分 − 300) / 650、负债率 / 100 归一化；输出为 ReLU，tanh 只控制亮度。视频输入 30、750、30 配合参数 0.9、0.8、−0.55、1.05 时，计算式为 `ReLU(0.9×0.3 + 0.8×450/650 − 0.55×0.3 + 1.05)`。

多层网络共用 `1600 → 16 → 16 → 10` 计算核心，隐藏层 Sigmoid，输出 Softmax。显示压缩为 8 个抽样输入节点，实际计算 1600 个输入。共有 26,058 个权重和偏置。

单样本损失为 `Σ(pᵢ−yᵢ)²`，批次对各样本损失求平均。Softmax 反向传播使用完整雅可比与上游梯度的乘积；隐藏层依次使用链式法则。所有样本的梯度在同一份更新前参数上计算，平均后统一更新。末尾不足一个完整批次时按实际样本数求平均。

箭头表示负的激活梯度 `−∂L/∂a`。箭头长度会为了显示而缩放；多箭头只展示前 3 项，汇总包含全部下游贡献。更新面板展示前 3 行与幅度较大的 3 个抽样列，列索引会显示在面板中；完整权重可在节点明细/矩阵中浏览。

前向/反向页面共用当前网络参数，训练模式页有独立网络。上一步不会撤销或重做参数更新，而是查看同一份计算快照。重置会恢复固定种子；重新随机参数会换一个种子。

数据为固定种子生成的数字笔画：每类 20 个训练样本、5 个独立验证样本，共 200/50 个，不是 MNIST。前景强度为 1、背景为 0，绘图时反转成白底黑字。训练指标、拟合误差和梯度均实时计算，不预设识别结果，也不强制损失下降。

教学曲面使用 `f(x)=0.09(x+0.8)²+0.55cos(1.7x)+0.65`，二维损失为 `f(x)`，三维为 `f(x)+f(y)`，并使用解析导数。曲线拟合使用 Chebyshev 基和两次正交化的最小二乘求解，训练点与验证点噪声独立。它们不是数字网络的实际损失切片或真实业务数据。

## 建议的体验顺序

1. 在神经元页将偏置降低到负值，观察 y 归零；提高偏置后再换第二组输入。
2. 前向页逐步点亮四层，点击隐藏层节点，翻看输入项并调整矩阵行列起点。
3. 反向页走完八步，比较更新前后损失；上一步再下一步，确认更新次数不增加。
4. 将学习率改大，再运行训练，观察损失是否震荡。二维/三维实验可拖动、点击或用滑杆选起点。
5. 在训练页分别选择三种更新方式，执行一批，观察样本数和平均梯度。用“公平对比”从同一起点比较完整一轮。
6. 遗忘实验先重置，点击“只练 0”，连续训练后暂停；再点“接着练 1”继续观察 0/1 验证指标。混合对照会重新初始化。
7. 在张量页查看维度组织，在拟合页调整多项式次数，比较训练与验证误差。
8. 导出模型，重置并重新导入；同一样本应恢复相同预测，且自动进入仅推理模式。

## 操作验收清单（待浏览器人工验收）

- [ ] 断网后双击打开，四个入口及本地资源正常工作；控制台没有异常。
- [ ] 输入/旋钮/公式/亮度联动，空值和越界数值在提交时得到处理。
- [ ] 前向四步可往返，Softmax 数值总和为 1（显示百分比有四舍五入误差）。
- [ ] 节点计算使用完整输入；矩阵任意行列可浏览。
- [ ] 反传八步与参数更新一致，重复查看第八步不会重复更新。
- [ ] 暂停、换页、重置、切换样本后不再执行旧的训练任务。
- [ ] 二维可选起点、观察切线；三维可旋转、选点、查看负梯度与分量。
- [ ] SGD 使用 1 个样本、全批量使用当前数据子集全部样本、小批量使用所选大小；最后一批使用剩余样本。
- [ ] 同批次样本先累积梯度再更新，表格平均值与 Δθ 一致。
- [ ] 公平对比使用相同种子、学习率和 200 个样本；独立比较不修改主网络。
- [ ] 遗忘实验切换阶段保留参数，混合对照重新初始化。
- [ ] 拟合验证点不参与参数求解；模型容量变化时误差真实变化。
- [ ] 导入有效文件恢复相同预测；无效尺寸/激活/版本/非有限数值文件被拒绝，原模型保留。
- [ ] 仅推理模式不能执行训练；切回训练后可继续。
- [ ] 桌面布局与关键帧对照；窄屏控件可操作，减少动画偏好生效。

## 文件组织

- `assets/core.js`：前向/反向/参数更新/模型序列化，纯数值运算。
- `assets/data.js`：确定性笔画数据、随机打乱及样本绘制。
- `assets/ui.js`、`assets/lab.css`：共用控件、图表与视觉样式。
- `assets/neuron.js`：单神经元。
- `assets/propagation.js`：网络 SVG、节点明细、传播快照和训练循环。
- `assets/experiments.js`：下山、拟合、张量补充实验。
- `assets/training.js`：批次平均、指标、比较、遗忘和模型文件。
- `assets/app.js`：Hash 导航、帮助弹窗与页面生命周期。

运行时为经典脚本，无 ES module / fetch / CDN，不依赖 `file://` 下的跨域读取。`jsconfig.json` 仅供开发检查；可以用已有 TypeScript 运行 `tsc -p jsconfig.json`，不会产生构建产物。
