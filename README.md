# AI Lesson

AI 课程视频、图文教程、演示文稿和制作脚本。

## 学习入口

双击项目根目录的 [index.html](index.html)，即可按「AI 基础」「Agents 底层逻辑」「Transformer」浏览全部课程的 HTML 图文文章和演示文稿，也可直接进入 Transformer 交互演示。支持课程搜索，无需启动服务器。

## 目录

- `video/`：AI 基础课程视频。
- `model/`：Agents 底层逻辑课程视频。
- `outputs/`：已生成的教程、演示文稿、PDF 和配套素材。
- `work/`：课程制作脚本与工作资料。
- `backup/`：已有备份资料。
- `beautiful-html-templates/`：演示文稿模板及其原始说明。

浏览器配置与缓存、Python 缓存、下载的本地运行工具及本地凭据文件不纳入版本控制。课程视频和其他资料以实际文件保存。
